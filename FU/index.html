Help Guide — استعمال کا طریقہ

Fuel & Profit Partner Tool | it.noorgee.com/FU

Step 1: Map Route — میپ پر روٹ لگائیں

Click on the map to add start & end points. Wrong point? Click the marker to remove it. Distance is auto-calculated with a 1.3x road multiplier for real-road accuracy.
غلط پوائنٹ پر کلک کریں تو وہ ہٹ جائے گا۔ سیدھی لائن × ۱.۳ = اصل سڑک کا فاصلہ

Step 2: Profit Tab — کمائی حساب

Enter Earn Amount, Commission (deducted), Addition Amount (bonus, added), Fuel Avg (L/km), and Petrol Price. Formula: Net Profit = Fare - Commission + Addition - Fuel Cost
کرایہ درج کریں، کمیشن منہا ہوگا، بونس جمع ہوگا، پیٹرول خرچ منہا ہوگا

Step 3: Fuel Expense Tab — پیٹرول خرچ

Enter refill amount and petrol price. System calculates Volume (L) and Efficiency (L/km). Use "Apply" button to use this average in Profit tab.
پیٹرول بھروائی کی رقم درج کریں، اوسط خود نکلے گا

Step 4: Login to Save — لاگ ان کریں

File → Register to create account. File → Login to access. Data saves both locally and in cloud database.
فائل مینو سے رجسٹر کریں، لاگ ان کریں، ڈیٹا محفوظ ہوگا
